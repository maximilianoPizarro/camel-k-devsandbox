= Kafka Messaging — Outer Loop

****
*Duration:* 10 min +
*Goal:* Deploy Integration `orders` against the same KRaft broker. Topology shows two Deployments. +
*Dev Spaces task:* *Outer — Kafka*
****

[IMPORTANT]
====
Stop the Inner Loop first: *Inner — Stop* (`camel stop`).
====

image::module-kafka.jpg[Kafka orders produce and consume,width=100%]

[NOTE]
====
*What changes from the Inner Loop*

* *Inner:* only the broker Deployment; Camel runs in the workspace against Service `kafka:9092`.
* *Outer:* Integration `orders` is a second Deployment; produce/consume logs come from the Integration pod.
====

== Deploy

[source,bash]
----
bash scripts/up.sh 03-kafka
----

Or *Outer — Kafka*. Applies the broker, waits for rollout, then the Integration.

== What to look for

. Topology: Deployments `kafka` and `orders`
. Logs of `orders`:

----
publicado pedido A-100
pedido recibido pedido A-100
----

[source,bash]
----
oc logs -l camel.apache.org/integration=orders --tail=40
----
