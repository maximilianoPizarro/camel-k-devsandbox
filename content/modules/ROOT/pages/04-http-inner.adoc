= HTTP Endpoint — Inner Loop

****
*Duration:* 5 min +
*Goal:* Serve `GET /hello` with Camel JBang on port 8081 (IDE already uses 8080). +
*Dev Spaces task:* *Inner — HTTP*
****

[IMPORTANT]
====
If an Integration is still running, clean it first: *Outer — Clean*.
====

image::module-http.svg[HTTP endpoint Inner and Outer paths,width=100%]

== Route

File: `labs/02-http/hello.camel.yaml` — `platform-http:/hello` returns plain text.

== Run

Stop any previous local Camel process first.

[source,bash]
----
source scripts/install-jbang.sh
camel stop 2>/dev/null || true
camel run labs/02-http/hello.camel.yaml --java-version=17 --jvm-args=-Xmx1024m --port=8081
----

Or *Inner — HTTP*.

From a *second* terminal:

[source,bash]
----
curl -fsS http://127.0.0.1:8081/hello
----

Expected: `Hola desde platform-http`
