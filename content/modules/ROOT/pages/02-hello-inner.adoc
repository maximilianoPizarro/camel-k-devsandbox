= Hello World — Inner Loop

****
*Duration:* 5 min +
*Goal:* Run the hello timer route with Camel JBang inside Dev Spaces. No Integration yet. +
*Dev Spaces task:* *Inner — Hello*
****

image::module-hello.svg[Hello World timer flow,width=100%]

== Route

File: `labs/01-hello/hello.camel.yaml`

. `timer:tick` every 10 seconds
. `setBody` to a greeting
. `log` writes to stdout

Open the file in Kaoto to see the canvas.

== Run

[source,bash]
----
source scripts/install-jbang.sh
camel run labs/01-hello/hello.camel.yaml --java-version=17 --jvm-args=-Xmx1024m
----

Or *Terminal → Run Task… → Inner — Hello*.

== What to look for

In the task terminal, lines like:

----
hello Hola desde Camel K en Developer Sandbox
----

Stop with Ctrl+C or *Inner — Stop* (`camel stop`).
