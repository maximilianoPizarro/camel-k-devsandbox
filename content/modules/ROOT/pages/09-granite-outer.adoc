= OpenShift AI + Granite — Outer Loop

****
*Duration:* 10 min +
*Goal:* Deploy Integration `granite` with Secret `sandbox-llm-token` and an OpenShift Route to `/ask`. +
*Dev Spaces task:* *Outer — Granite*
****

[IMPORTANT]
====
Stop the Inner Loop first: *Inner — Stop* (`camel stop`).
====

image::module-granite.svg[Granite ask flow,width=100%]

[NOTE]
====
*What changes from the Inner Loop*

* *Inner:* `export LLM_TOKEN=$(oc whoami -t)` in the process environment; HTTP on port 8081.
* *Outer:* Secret `sandbox-llm-token` + trait `environment`; Route HTTPS; same `SandboxTrust.java` in the kit.
====

== Deploy

[source,bash]
----
bash scripts/up.sh 04-granite
----

Or *Outer — Granite*. Creates the Secret from `oc whoami -t` (not in git). Trait `environment` injects `LLM_TOKEN`.

The route strips `CamelHttp*` and `Host`, then POSTs with `bridgeEndpoint=true` and `#sandboxSsl`. Without that, the model returns 404.

== What to look for

[source,bash]
----
HOST=$(oc get route/granite -o jsonpath='{.spec.host}')
curl -kfsS --max-time 180 "https://${HOST}/ask"
----

Try more queries (URL-encode spaces as `+`):

[source,bash]
----
curl -k "https://${HOST}/ask?q=Escribe+una+ruta+Apache+Camel+en+YAML+que+lea+de+Kafka+y+escriba+en+un+log"
curl -k "https://${HOST}/ask?q=Que+ventaja+tiene+publicar+una+integracion+como+herramienta+MCP+en+lugar+de+API+REST"
----

If you get 401, the token expired — re-run *Outer — Granite*.
