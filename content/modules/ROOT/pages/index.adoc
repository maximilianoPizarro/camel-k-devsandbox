= Red Hat Apache Camel Day Roadshow

== Workshop Overview

You will design Apache Camel routes visually with Kaoto, run them instantly inside OpenShift Dev Spaces with Camel JBang (**Inner Loop**), then deploy the same YAML with the Camel K operator (**Outer Loop**). Along the way you call a Kafka broker, an OpenShift AI model, and publish an MCP tool.

This is a hands-on workshop on Apache Camel K, Camel JBang, Kaoto, and OpenShift AI on the Red Hat Developer Sandbox.

****
*Duration:* ~2 hours +
*Format:* Hands-on workshop (self-service Dev Spaces) +
*Repo:* {repo_url}
****

== Inner Loop and Outer Loop

Every lab uses the same `*.camel.yaml` file. First you run it in the workspace; then you apply it as an Integration.

image::inner-outer-loop.jpg[Inner Loop and Outer Loop,width=100%]

[cols="1,2"]
|===
|Loop |What it means

|*Inner Loop*
|Edit the route in Kaoto, run `camel run` in the Dev Spaces terminal. No image build. Fast feedback on port `8081` (or logs for timer routes).

|*Outer Loop*
|`scripts/up.sh` syncs the YAML into an Integration CR. The Camel K operator builds a kit (S2I, routine), deploys a pod, and may expose an OpenShift Route.
|===

== Architecture

image::camel-architecture.jpg[Camel Day Roadshow architecture,width=100%]

[cols="1,2"]
|===
|Component |Description

|OpenShift Dev Spaces
|Cloud IDE with Kaoto and Camel JBang in the Universal Developer Image

|Camel JBang 4.22
|Inner Loop runtime: `camel run` on the same YAML

|Camel K operator 2.11
|Outer Loop: watches Integrations, builds kits, deploys pods

|Apache Kafka (KRaft)
|Single-broker Deployment for the orders lab (no Strimzi CRD needed)

|OpenShift AI (Granite)
|Shared GPU predictor `isvc-granite-31-8b-fp8` in `sandbox-shared-models`

|MCP Server
|`camel-quarkus-mcp-server` exposing `ai-tool` routes as tools
|===

== What You Will Learn

* *Lab Setup* -- Open the repo in Dev Spaces, install JBang, use Kaoto and Topology.
* *Hello World* -- Timer and log, Inner then Outer.
* *HTTP* -- `platform-http`, local port 8081, then OpenShift Route with edge TLS.
* *Kafka* -- Produce and consume on a minimal KRaft broker.
* *Granite* -- Call OpenShift AI with TLS trust to the service CA.
* *MCP* -- Publish `order-status` as a tool and ask Granite about an order.
* *Wrap-up* -- Clean up and next steps.
