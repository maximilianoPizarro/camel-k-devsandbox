= Wrap-up

****
*Duration:* 5 min +
*Goal:* Recap Inner vs Outer Loop and leave the project clean.
****

== What you practiced

[cols="1,2"]
|===
|Loop |Skills

|*Inner Loop*
|Kaoto canvas, `camel run`, port 8081, JBang Quarkus for MCP tags, curl against localhost

|*Outer Loop — Deploy*
|Integration CR, IntegrationPlatform (routine + S2I), Routes with edge TLS, Secrets for LLM token, builder traits
|===

The shared artifact is always the lab `*.camel.yaml`.

== What changes between loops (all labs)

[cols="1,2,2"]
|===
|Lab |Inner |Outer

|Hello
|Logs in the `camel run` terminal
|Pod `hello`, container logs in Topology

|HTTP
|Port 8081, `curl` to localhost
|Port 8080 in the pod, Route HTTPS with edge TLS

|Kafka
|`camel run` against Service `kafka` (broker only)
|Integration `orders` plus the broker

|Granite
|`LLM_TOKEN` in the process environment
|Secret + trait `environment`

|MCP
|`--runtime=quarkus` and `--property` / `--dep` flags
|Trait `builder` + `mvn:` dependencies
|===

== Clean up

Outer Loop resources (Integrations, Kafka Deployment, Secrets labeled for the workshop):

[source,bash]
----
bash scripts/down.sh
----

Or *Outer — Clean*. Does *not* stop Camel JBang.

Inner Loop process:

[source,bash]
----
camel stop
----

Or *Inner — Stop*.

Leave the IntegrationPlatform `camel-k`, CamelCatalogs, and `modelmesh-serving` Service in place.

== Beyond this workshop

This roadshow stops at *Outer Loop — Deploy*. A fuller Outer Loop would add:

* *Automate* -- Git commit, OpenShift Pipelines (Tekton), and/or OpenShift GitOps (Argo CD) to promote the same YAML
* *Operate* -- health, metrics, build logs, and day-2 actions on the Integration

Those steps need more quota and cluster features than the Developer Sandbox workshop assumes.
